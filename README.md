# Valters

Personīgais šaha asistents Valteram Avotiņam (FIDE 11662255).

Dati tiek nolasīti tikai no [chess-results.com](https://chess-results.com/). Poga **Atjaunot** pārlasa turnīrus, pretiniekus, rezultātus un spēles vietu.

## Kas ir redzams

- turnīri ar datumu, vietu, punktiem un rangu
- katra partija: pretinieks, krāsa, rezultāts
- pretinieku kopsavilkums: cik reižu spēlēts un kā veicies

## Palaišana

```bash
npm install
npm run dev
```

Izstrādes serveris klausās portu 8080.

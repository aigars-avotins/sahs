# AI piezīmes šim projektam

Kad mainās produkta uzvedība, AI tajā pašā solī atjauno dokumentāciju. Kodu neraksta apraksta vietā un otrādi.

## Kur kas glabājas

- GitHub, šis repozitorijs: prasības `docs/prasibas.md` un implementācija `docs/implementacija.md`.
- GitLab: user stāsti un arhitektūra. Tur ir jāpaliek to izmaiņu vēsturei. Šos divus dokumentus GitHub nedublē.
- GitLab projekta adrese vēl nav zināma. Kamēr tās nav, user stāstus un arhitektūru necommitot šeit. Vispirms jāpajautā adrese.

## Rakstot

- Valoda ir latviešu.
- Raksta tikai to, ko lapa tiešām dara. Nav solījumu par datiem, kurus chess-results nav atdevis.
- Prasību fails paliek īss. Sīkas atstarpes un pikseļi paliek implementācijas failā tikai tad, ja tie ir apzināts lēmums, nevis katras pabīdes žurnāls.
